# How to Generate a Farcaster Signer (2026)

## Method 1: Using the Official Farcaster CLI

### Step 1: Install Farcaster tools

```bash
npm install -g @farcaster/core @farcaster/hub-nodejs
```

### Step 2: Generate a signer programmatically

Create a file `generate-signer.js`:

```javascript
import { ed25519 } from '@noble/curves/ed25519';
import * as fs from 'fs';

// Generate random private key (32 bytes)
const privateKey = ed25519.utils.randomPrivateKey();

// Convert to hex
const privateKeyHex = Buffer.from(privateKey).toString('hex');

// Derive public key (64 bytes for ed25519)
const publicKey = ed25519.getPublicKey(privateKey);
const publicKeyHex = Buffer.from(publicKey).toString('hex');

console.log('Private Key (keep secret):');
console.log('0x' + privateKeyHex);

console.log('\nPublic Key:');
console.log('0x' + publicKeyHex);

// Save to file
fs.writeFileSync('signer.json', JSON.stringify({
  private_key: '0x' + privateKeyHex,
  public_key: '0x' + publicKeyHex
}));

console.log('\nSaved to signer.json');
```

### Step 3: Run it

```bash
node generate-signer.js
```

### Step 4: Register your signer with Farcaster

You'll need to register your signer in the Farcaster network. This is done through a Farcaster client app or using their API.

## Method 2: Using Warpcast Web App

1. Go to **https://warpcast.com**
2. Sign in (or create an account)
3. Click your profile icon → Settings
4. Look for "Security" or "Signers" section
5. Click "Generate Signer"
6. Save the private and public keys shown

**Note:** The exact UI path may have changed. If you can't find it:
- Check Settings → Security
- Check Settings → Account → Signers
- Look for "API Keys" or "Developer" sections

---

## Method 3: Use Farcaster Hub (Alternative)

If you prefer not to manage signers yourself:

1. Go to https://docs.farcaster.xyz
2. Create an account
3. Create a new signer through their dashboard
4. Copy the signer UUID and API key
5. Use these in your bot config

## For the @homiehouselol Bot

The bot expects these environment variables:

```bash
SIGNER_PRIVATE_KEY_HEX=0x...
SIGNER_PUBLIC_KEY_HEX=0x...
APP_FID=12345678  # Your Farcaster ID
ANTHROPIC_API_KEY=...
```

**Where to get each:**
- `SIGNER_PRIVATE_KEY_HEX` & `SIGNER_PUBLIC_KEY_HEX`: Generated by one of the methods above
- `APP_FID`: Your Farcaster user ID (shown in your profile on warpcast.com)
- `ANTHROPIC_API_KEY`: Your Anthropic API key

## Testing Your Signer

Once you have your keys, test them by making a small test cast:

```bash
curl -X POST https://hub.farcaster.xyz/api/rpc \
  -H "Content-Type: application/json" \
  -d '{
    "jsonrpc": "2.0",
    "method": "casts_add",
    "params": [{
      "fid": YOUR_FID,
      "text": "Testing signer",
      "timestamp": '$(date +%s)',
      "signer": "YOUR_PRIVATE_KEY_HEX"
    }],
    "id": 1
  }'
```

If it works, you'll get back the cast hash.
